IMPORTANT LIMITATION:
This version runs on static GitHub Pages and stores bookings/content in each visitor/owner browser’s localStorage. A customer booking will open WhatsApp and be stored in the browser which submitted it; it will NOT automatically arrive in a central admin database. Backup/export protects the current browser's records. True shared backend, multi-device admin data, and genuine email OTP require a separately configured cloud database/server with credentials and security rules. Static JavaScript/admin-config credentials are not private; do not use this as a highly secure production login.

Default call and WhatsApp number: +91 98274 30197. Confirm it is the number you supplied for WhatsApp before going live.
